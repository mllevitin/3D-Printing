# AlphaServer DS10 short stand - v0.4

Use **two identical stands** for one case. One stand measures **200 × 50 × 76.93 mm**. Clear slot: **130.5 mm**; retaining walls: **6.3 mm**; base thickness: **6 mm**. All models use millimeter units and 1:1 scale.

## Printing

[Ready-to-print pair](printing/ds10_v04_two_stands_QIDI_Q2_PLA.gcode.3mf) · [G-code](printing/ds10_v04_two_stands_QIDI_Q2_PLA.gcode) · [Settings and checksums](printing/print_settings.json).

QIDI Q2, 0.4 mm nozzle, PLA, 230/55 °C, 0.28 mm layers, 4 wall loops, 25% gyroid, 16 mm³/s flow. Slicer estimate for a pair: **4h 9m 20s / 173.54 g**. The package contains both stands and is unchanged from the completed print. Select the physical filament slot on your printer; the test print used spool 1B.

[Printing instructions](../../docs/PRINTING.md), [design dimensions](../../docs/DESIGN.md), [source and rebuilding](../../docs/BUILD.md).

Top trimmed at the middle gusset junction. The slot is 130.5 mm; original slopes and exterior geometry below the trim plane are preserved.
